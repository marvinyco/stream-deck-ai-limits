Profile 1 is the top pair of bars (left on a dial), profile 2 the bottom pair. Labels only appear when a profile cannot load, to say which one failed.
Each credentials field takes the full path to a Claude Code .credentials.json. Leave it empty to use the default login (%USERPROFILE%\.claude\.credentials.json). A Claude Code profile in WSL looks like \\wsl$\<distro>\home\<user>\.claude\.credentials.json.
